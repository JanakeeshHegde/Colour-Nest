## 🛠️ Technology Architecture

- **Core:** React 18, Vite, JSX, JavaScript (ES Modules)
- **Routing:** React Router DOM v6 with route transitions and auto scroll-to-top
- **Animation & Kinetics:** Framer Motion, GSAP, GSAP ScrollTrigger
- **Smooth Inertia:** Lenis
- **Iconography:** Lucide React
- **Design System:** Pure Vanilla CSS Architecture (CSS Variables, responsive fluid clamp typography, dynamic accent shifts, dark charcoal/warm plaster themes, zero external CSS bloat)
- **SEO & Schema:** `react-helmet-async` with comprehensive `LocalBusiness` JSON-LD structured data
- **Client Features:**
  - Client-side `.vcf` vCard contact generation via Blob
  - Client-side QR code generation & image download
  - WhatsApp link encoder with formatted spatial consultation briefs
  - Interactive 3D virtual light source simulation over Venetian textures
  - Before / After interactive transformation divider with 5 atmosphere modes
  - Curated 5-colour palette engine with clipboard hex copying and localStorage persistence
  - 4-question Style Finder diagnostic quiz
